# Atividade prática -  Engenharia de requisitos

## 1.Quem utilizará o sistema?
Professores, coordenadores e a secretaria da escola

## 2.Cite 3 requisitos funcionais
* O sistema deve permitir criar, editar e consultar a ficha de cadastro do aluno(nome, data de nascimento, documentos e endereço);
* O sistema deve permitir que professores lancem faltas e as notas de cada aluno;
* O sistema deve permitir que a secretaria associe cada professor especificamente às turmas e disciplinas em que ele leciona. 

## 3.Cite 2 requisitos não funcionais
* O sistema deve exigir login e senha, garantindo que somente pessoas autorizadas acessem certas informações sensíveis;
* O sistema deve carregar qualquer listagem de alunos ou relatórios em menos de 2 segundos, mesmo sob uma base de dados com mais de 10.000 estudantes ativos. Para isso, todas as tabelas devem implementar paginação no lado do servidor (_server-side pagination_).

## 4.Explique, em poucas palavras, por que é importante levantar os requisitos antes de desenvolver um software.
Levantar os requisitos antes de programar é essencial porque garante que o software vá atender às reais necessidades dos usuários, evitando retrabalho, desperdício de tempo e custos extras. É o planejamento que alinha as expectativas da escola com o que os desenvolvedores vão construir. O processo de levantamentos de requisitos ajuda a evitar erros, e adicionar ferramentas e funções que ajudem na acessibilidade do usuário.
